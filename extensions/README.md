# Extension details

Every MiniTools extension is optional. Installing one enables its tab and
compact-island experience; uninstalling it removes the feature without deleting
its saved preferences.

## Agent Pulse

**Category:** Developer tools  
**Capabilities:** Process inspection, notifications

Connects MiniTools to local Codex activity. It can show active work, completion,
or help-needed states and animate the perimeter of the collapsed island while an
agent is running. It does not store prompts or conversation contents.

[Download Agent Pulse](../packages/AgentPulse-0.1.0.minitoolplugin)

## Caffeine

**Category:** Utilities  
**Capabilities:** Keep awake

Prevents idle sleep for a selected duration or indefinitely. Its compact view
exposes the current session and its optional notch indicator supports color and
thickness controls.

[Download Caffeine](../packages/Caffeine-0.1.0.minitoolplugin)

## Launchpad

**Category:** Productivity  
**Capabilities:** Application discovery, application launch

Creates a compact launcher from apps dropped from Finder or the Dock. Favorites
remain local and can be reordered or removed at any time.

[Download Launchpad](../packages/Launchpad-0.1.0.minitoolplugin)

## Mini Terminal

**Category:** Developer tools  
**Capabilities:** Terminal session

Runs the user's real login shell through a PTY, with interactive input, terminal
signals, history, and a configurable font size. Commands execute locally under
the current user account.

[Download Mini Terminal](../packages/MiniTerminal-0.1.0.minitoolplugin)

## Ports

**Category:** Developer tools  
**Capabilities:** Process inspection, process termination

Lists local TCP and UDP listeners, the owning process, and the port. Termination
is always an explicit user action.

[Download Ports](../packages/Ports-0.1.0.minitoolplugin)

## Screenshot Board

**Category:** Productivity  
**Capabilities:** Screenshot events, file drag and drop

Collects recent macOS screenshots in the island and exposes native file drags so
they can be dropped into Finder, messages, editors, and other apps.

[Download Screenshot Board](../packages/ScreenshotBoard-0.1.0.minitoolplugin)
